pidof:
pidof command in Linux is a command-line utility used to find the exact process ID (PID) of a running program by its binary name.

pidof [OPTIONS] program_name

eg: pidof nginx

killall:
The killall command in Linux terminates processes by their exact name rather than their Process ID (PID).

killall [process_name]
eg: killall firefox

killall firefox sends a SIGTERM signal by default, allowing the app to save data.

killall -9 firefox (or killall -s KILL firefox) sends a SIGKILL signal, instantly terminating the process without saving.

curl/wget

The primary difference is that wget is a dedicated tool for downloading files, while curl is designed to transfer data to and from a server

wget:
Downloading files/directories.
Saves straight to a file.
Recursive Downloading: Built-in (can mirror whole sites).
Supported Protocols: Few (HTTP, HTTPS, FTP, FTPS).
standalone utility

wget: Automatically saves the file locally using its remote name.
wget https://example.com/file.zip

wget: Uses an uppercase -O:
wget -O my_filename.zip https://example.com/file.zip

Interacting with REST APIs (POST Requests)
wget: Features limited payload and header control.

you are downloading large files or large groups of files over a shaky network connection (it handles connection drops and resumes brilliantly).
You need to mirror an entire website or directory.
You want a long-running download job to immediately execute in the background while you close your terminal session

curl:
curl acts like a network "Swiss Army knife" optimized for bidirectional data transfer, complex protocol handling, and scripting.
Bi-directional data transfer.
Prints directly to the terminal screen (stdout).
Extensive (HTTP, FTP, SFTP, SCP, SMTP, POP3, etc.).
Background Support: Relies on standard Linux shell operations (&, nohup).

downloading files:
curl: You must explicitly instruct it to save the file. Lowercase -o lets you name it manually; uppercase -O uses the remote filename.
curl -O https://example.com/file.zip

curl: Uses a lowercase -o:
curl -o my_filename.zip https://example.com/file.zip

3. Interacting with REST APIs (POST Requests):
curl -X POST -H "Content-Type: application/json" -d '{"user":"linux"}' https://example.com

Choose curl if:You are testing, querying, or scripting interactions with a web API.
You want to upload data or send complex HTTP request methods (POST, PUT, DELETE).
You are writing scripts where the data should be piped immediately into another tool (e.g., parsing JSON directly into jq).
You need to communicate over protocols outside of standard web traffic, like SFTP, SCP, or SMTP.
