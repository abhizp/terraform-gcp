4. Kernel Initialization
The kernel decompresses itself into memory and sets up core hardware clocks, interrupts, and memory management.
Initializes essential device drivers compiled directly into the kernel or available as modules.
Mounts the temporary root filesystem provided by initramfs to handle early hardware discovery (like RAID or LVM).


5. Initramfs and Transition to Root:
initramfs runs initial scripts via udev to dynamically detect connected hardware and load required storage drivers.
The real, permanent root filesystem is checked for errors and mounted read-write.
The temporary initramfs memory is cleared, and control transitions to user-space


6. systemd (PID 1) and Targets:
The kernel launches systemd as the very first user process with Process ID 1 (PID 1).
systemd reads configuration units to mount remaining filesystems, set the hostname, and launch background daemons (networking, logging).
Reaches the default target state (multi-user text mode or graphical desktop target) and launches the login prompt
